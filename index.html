Agregar negocio

Conceptos de conciliación

Define las categorías de "lo recibido" para este negocio (cada negocio puede tener las suyas).

Categorías de venta

Define qué vende este negocio (Alimentos, Bebidas, Daypass, etc.) — cada negocio puede tener las suyas.

Catálogo de cuentas

Crea tus cuentas mayor (ej. Nómina, Servicios, Pasivos, Otros Ingresos) y dentro de cada una sus subcuentas — así se clasifican los gastos e ingresos en el P&L y las pólizas de diario.

Catálogo de proveedores

Da de alta tus proveedores una vez; luego los seleccionas al capturar facturas o pagos.

El Excel debe tener columnas "Nombre Comercial" y "Razón Social" (una fila por proveedor).

Desglose de factura

Reparte el importe de esta factura entre las subcuentas que correspondan.

Traspaso entre cuentas

Mueve dinero entre bancos y/o cajas de efectivo del mismo negocio. Se registra automáticamente en ambas cuentas.

Agregar movimiento

Elegir facturas a pagar

Marca todas las que se paguen con este movimiento. Se marcarán como "Pagado" al aplicar.

Usuarios autorizados

Solo estos correos pueden entrar a Finanzas (aunque tengan cuenta compartida con tus otras apps). Escribe el correo exacto con el que inician sesión.
